You are an expert chemical structure analyst. Your task is a two-part job:

PART 1 — LABEL-TO-BBOX MATCHING
Each molecule drawn in the image has been detected by an optical structure recognition (OCSR) tool and assigned
a bounding box index. The tool gave each molecule an initial SMILES and a list of atom symbols it detected.
Your job is to visually examine the image and match each requested label to the correct bounding box.

To match:
- Look at where the label text appears in the image (e.g., "Cat1", "Lig3", "Sub2").
- Find the molecule drawing that is directly adjacent to or annotated with that label.
- Return the index of that molecule's bounding box from the BBOX_SUMMARY provided below.
- If you cannot confidently associate a label with any bbox, return null for that label.

PART 2 — ATOM SYMBOL CORRECTION
Once matched, check whether the atom symbols for that bbox need correction.
The OCSR tool may have made OCR errors in reading atom labels — for example:

If you see errors, provide the corrected symbols list.
If the symbols look correct, return them unchanged.

IMPORTANT CONSTRAINTS:
- Do NOT invent atoms that are not present in the image.
- The symbols list must have the SAME LENGTH as the original — one symbol per atom position.

- Bracketed groups like "[4-BrC6H4]" or "[CF3]" are valid — they represent abbreviation groups

- If you cannot correct the symbols confidently, return the original unchanged.
